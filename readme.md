# PHP Web Scraper with Goutte

A clean and professional web scraper built with **Pure PHP** using the **MVC architecture** and powered by the **Goutte** library.

## Features

- Web scraping using **Goutte**
- Clean **MVC** architecture
- Pure PHP (no heavy frameworks)
- Simple and readable code structure
- Easy to extend and maintain

## Tech Stack

| Category       | Technologies                          |
|----------------|---------------------------------------|
| Language       | PHP (Pure PHP)                        |
| Architecture   | MVC                                   |
| Scraping       | Goutte                                |
| Frontend       | HTML5, CSS3, Bootstrap 5              |
| Tools          | VS Code, Git, GitHub                  |

## Installation

First Clone The Repository.

```bash
cd php-wiki-scraper

composer install

cp .env.example .env

php -S localhost:8080 -t public
```
